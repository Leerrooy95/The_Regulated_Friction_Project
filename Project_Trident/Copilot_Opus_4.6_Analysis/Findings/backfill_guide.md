**2025:** 330 friction / 673 compliance (7.7x / 9.1x the 2015-18 average)

This imbalance means:
1. Pearson correlations are dominated by high-count 2025 weeks
2. Granger causality only appears when 2025 data is included
3. Cross-year comparisons are unfair — 2025 has 10x the coverage

## Backfill Strategy

### What to backfill:

1. **Compliance events (2015-2018):** Major US policy events, international
   agreements, infrastructure legislation, tech/defense deals, financial
   regulation changes

2. **Friction events (2015-2018):** Epstein-related legal proceedings,
   geopolitical friction events, major scandals, whistleblower actions

### Sources (in priority order):

1. **Government records:** congress.gov, federalregister.gov, whitehouse.gov
2. **Court records:** courtlistener.com, PACER
3. **News archives:** NYT, Washington Post, Miami Herald (Epstein-specific)
4. **International organizations:** un.org, state.gov

### What NOT to backfill:

- Events that cannot be independently verified
- Events chosen to strengthen or weaken the correlation
- Events outside the friction/compliance framework
- Duplicate events already in the dataset

## Impact Assessment

### Adding 49 backfill events changes correlations by:

| Metric | Original | Backfilled | Change |
|--------|----------|------------|--------|
| Pearson r | 0.1099 | 0.1098 | -0.0001 |
| Spearman ρ | 0.6067 | 0.5729 | -0.0338 |

**Conclusion:** The backfill has **minimal impact** on correlations.
The Spearman ρ decreases slightly (-3.4%) because the new events add
non-zero weeks to previously empty periods, slightly reducing the
rank-order concentration.

### Granger impact:

- F→C lag 2 shifts from p=0.048 (barely significant) to p=0.053
  (barely non-significant) — **borderline change**
- C→F direction unchanged
- Excluding all 2025: still no Granger causality in either direction

### Bottom line:

49 events is a **small** backfill relative to the 2,951 original events.
A comprehensive backfill would require systematic scraping for 2015-2018
using the same methodology applied to 2025 — likely yielding hundreds
of additional events per year. The user should apply this methodology
if truly balanced cross-year comparisons are desired.
