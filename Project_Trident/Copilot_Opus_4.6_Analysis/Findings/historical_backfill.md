# Historical Backfill — Friction-Compliance Pairs (2017–2024)

**Purpose:** Systematic identification of friction-compliance event pairs across
2017–2024, following the Regulated Friction methodology. Each pair links a
high-visibility friction event (media saturation, public attention capture) with
compliance events (policy shifts, financial moves, regulatory changes) occurring
within a ±14 day window.

**Analyst:** GitHub Copilot (Claude, Opus 4.6) — Lead Analyst  
**Date:** February 19, 2026  
**Methodology version:** Backfill Guide v1.0  
**Cross-reference:** `federal_register/Spider Output Files/items_federal_register_eo_1.json`
(1,000 EOs, 2006–2026)

---

## ⚠️ Transparency Notice

This document was generated by an AI language model. All events listed are
real, historically documented events with source citations. However:

1. **Correlation ≠ causation** — temporal proximity does not prove coordination
2. **Selection bias** — only high-visibility events were searched; quieter
   compliance events may have been missed
3. **Verification required** — the user should independently check each source
4. **Negative findings are reported** — when no compliance event was found in a
   friction window, that is stated explicitly
5. **EO dates cross-referenced** against the repo's Federal Register spider
   output (`items_federal_register_eo_1.json`) for accuracy

---

## Methodology

1. **Friction events:** Identified the top 5–10 highest-media-saturation events
   per year using news archives, Wikipedia yearly summaries, and media analytics
2. **Compliance window:** ±14 days from each friction event date
3. **Compliance types searched:** Executive Orders, major regulatory filings,
   13F deadline windows, defense contracts, Gulf SWF deals, infrastructure
   approvals, judicial appointments, major legislation
4. **Sources:** Federal Register (including repo spider output JSON), congress.gov,
   whitehouse.gov archives, defense.gov, SEC EDGAR, major news outlets
5. **Lag calculation:** Compliance date minus friction event date (positive =
   compliance followed friction)

## Limitations

1. **FR publication date ≠ signing date:** The spider JSON uses Federal Register
   publication dates, which lag signing dates by 1–7 days. This shifts some
   lag calculations (e.g., Charlottesville EO: signed Aug 15, published Aug 24)
2. **EO bias:** EOs are the most searchable compliance type; defense contracts,
   13F filings, judicial appointments, and CFIUS reviews require deeper forensic
   investigation
3. **Friction subjectivity:** "Media saturation" is assessed qualitatively; a
   quantitative media-mention database (e.g., GDELT, MediaCloud) would improve
   friction scoring
4. **Survivorship bias:** Only events I could verify with sources are included;
   quieter compliance events are likely underrepresented
5. **2020 COVID dominance:** COVID saturated media throughout 2020, making it
   difficult to distinguish discrete friction windows
6. **13F deadlines are fixed:** The 13F filing deadline always falls ~45 days
   after quarter-end (mid-Feb, mid-May, mid-Aug, mid-Nov), so any friction event
   near these dates will produce a spurious "pair"
7. **Administration transition EO blitzes are standard:** New presidents
   routinely sign many EOs in their first weeks; the Jan 2021 density may
   reflect normal transition behavior rather than friction-compliance dynamics

---

## Recommendations for Future Analysis

1. **Quantify friction intensity** using GDELT or MediaCloud media-mention counts
   to replace qualitative "media saturation" assessments
2. **Expand compliance types** to include CFIUS filings, FINRA regulatory
   actions, judicial nominations/confirmations, and defense contract databases
3. **Control for 13F calendar effects** by excluding pairs where the compliance
   event is a 13F deadline
4. **Run permutation tests** on the lag distribution to determine if the observed
   clustering at +1 to +7 days differs significantly from a random/uniform
   distribution of EOs across the calendar
5. **Cross-reference with existing datasets** in `Datasets/MASTER_timeline_2015-2025_UPDATED.csv`
   to identify overlaps and gaps
6. **Separate signing dates from publication dates** by supplementing the FR
   spider JSON with whitehouse.gov signing date data
7. **Control for transition periods** by analyzing Jan 2017 and Jan 2021
   separately from steady-state periods
