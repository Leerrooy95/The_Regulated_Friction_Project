## Key Finding

**The discrepancy is explained primarily by zero inflation and measurement
type — NOT by sample size or temporal coverage.**

The event-count dataset has **84.2% zero-count friction weeks** and **86.5%
zero-count compliance weeks**, with 80.3% of all weeks having zero events in
both series. This extreme sparsity means the event-count Granger test is
dominated by zero-zero pairs, which carry no predictive information.

The hand-scored dataset has **zero zeros** — every week has a non-zero
intensity rating (1-10), reflecting the scorer's judgment that *something*
always happens, just at varying intensity levels.

## Four Hypotheses Tested

### H1: Measurement Type ✅ CONFIRMED (Primary explanation)

| Metric | Hand-Scored | Event-Count |
|--------|-------------|-------------|
| Scale | 1-10 intensity | 0-259 raw counts |
| Zeros | 0% | 84-87% |
| CV (std/mean) | 0.52 / 0.58 | 8.59 / 5.83 |
| Information content | Every week rated | Most weeks empty |

The hand-scored indices compress a week's worth of events into a single
intensity judgment. A week with one major Epstein document release might
score friction=9, while a week with 20 minor policy updates might score
compliance=4. Event counts would reverse this weighting.

**Log-transform test:** When event counts are log-transformed (log(1+x),
which compresses magnitudes similarly to hand-scoring), Granger causality
becomes significant in BOTH directions at ALL lags. This confirms that
magnitude compression changes the Granger result.

**Rank-transform test:** Rank-transforming event counts (to mimic ordinal
hand-scoring) also produces bidirectional Granger at all lags.

### H2: Sample Size — PARTIALLY SUPPORTED

Bootstrap analysis: 500 random 30-week windows from the event-count data,
testing Granger at lags 1-2:

| Outcome | Count | Percentage |
|---------|-------|------------|
| F→C only (unidirectional) | 16 | 3.2% |
| C→F only (reverse) | 27 | 5.4% |
| Bidirectional | 2 | 0.4% |
| Neither | 455 | 91.0% |

**Finding:** Only 3.2% of random 30-week windows show unidirectional F→C.
This means the hand-scored F→C finding is unlikely to be a chance artifact
of the window size — the 30-row dataset captures something specific.

### H3: Temporal Coverage — NOT SUPPORTED

Testing on the densest 30-week window in the event-count data (starting
2025-05-26, 750 total events):
- F→C: ✗ No significant lags
- C→F: ✗ No significant lags

Even the period with the most events doesn't produce Granger causality in
a 30-week window. The hand-scored dataset's F→C finding is NOT simply
because it covers a "busy" period.

### H4: Zero Inflation ✅ CONFIRMED (Secondary explanation)

- 80.3% of all weeks have ZERO events in BOTH friction AND compliance
- Removing all-zero weeks leaves only 371 weeks (from 1,879)
- Granger on non-zero weeks only: ✗ No significance in either direction

The zero inflation is so extreme that even removing zeros doesn't rescue
the event-count Granger test — the remaining 371 non-consecutive weeks
lack the temporal contiguity needed for lag-based analysis.

## Synthesis

| Factor | Role in Discrepancy | Evidence |
|--------|-------------------|----------|
| Zero inflation | Primary | 84% friction / 87% compliance weeks are zero |
| Measurement type | Primary | Hand-scoring captures intensity; counts don't |
| Magnitude compression | Supporting | Log and rank transforms change Granger results |
| Sample size | Minor | Only 3.2% of random 30-week windows show F→C |
| Temporal coverage | Not a factor | Densest event-count window shows no Granger |

### What this means for the thesis:

The friction→compliance sequential mechanism is best measured by
**intensity indices** (how *important* was this week's friction?) rather
than raw event counts (how *many* friction events occurred?). The 30-row
hand-scored dataset captures this intensity — and the F→C Granger finding
in that dataset survives first-differencing (Task 2), making it the most
robust statistical evidence for the sequential mechanism.

The event-count dataset is too sparse and coarse to detect this mechanism.
This is a **data quality limitation**, not a disconfirmation of the thesis.

### Recommendation:

Future analysis should use intensity-weighted scoring rather than raw event
counts. Options include:
1. Extend the hand-scored dataset beyond 30 weeks
2. Use media coverage volume as a proxy for friction intensity
3. Use financial magnitude (deal size) as a proxy for compliance intensity
4. Apply log or rank transforms to event counts before testing
