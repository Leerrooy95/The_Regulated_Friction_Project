What This Means

When high-visibility friction events spike—document releases, scandals, media cycles—institutional compliance events (policy shifts, financial positioning, regulatory changes) follow approximately 14 days later. This correlation has less than a 0.05% probability of occurring by chance.

The project does not claim causation, conspiracy, or individual intent. It documents a statistically significant structural pattern: friction and compliance events cluster together in time, suggesting shared exploitation of calendar-driven attention windows by independent actors.

Methodology

Core Analysis

Pearson product-moment correlation with lag sweep (0–6 weeks). Fisher z-transform for confidence intervals. Spearman rank correlation for robustness. OLS regression with ±2 SD prediction bands.

Robustness Testing

16 independent tests including permutation (1K shuffles, p<0.001), block bootstrap for autocorrelation, December 2025 exclusion, binary normalization, event-study framework (20–42x baseline), and Granger causality.

Historical Backfill

66 friction-compliance pairs across 30 windows (2017–2024). 89% positive lag pattern. 5 confirmed negative windows within expected statistical variance (binomial test: p = 0.006).

Additional Findings

Project Trident

Temporal correlation study (118 ritual/policy event pairs). Ritual event proximity to policy: 50.7% vs 19.9% baseline (2.5x expected rate). Mann-Whitney U: p = 0.002.

Cross-Validation

14-day periodicity test across 2,102 events: χ² = 330.62 (p < 0.0001). Multi-dataset Spearman rank: ρ = 0.61 (p < 0.0001). Event colocation: 20–42x above random baseline.

Convergence Model

Revised finding: multiple actors respond independently to shared calendar anchors (holidays, solstices, fiscal deadlines), creating simultaneous convergence rather than sequential causation.

Correlation is not causation. This site presents observational statistical patterns for research purposes only. The friction-compliance correlation (r = 0.6196) describes a measured association, not a proven causal mechanism. All findings are reproducible using the scripts in Run_Correlations_Yourself/.

Statistical methods: Pearson product-moment correlation with lag sweep (0–6 weeks), Fisher z-transform for confidence intervals, Spearman rank correlation for robustness, OLS regression with ±2 SD prediction bands. Historical backfill analyzed via lag-day distribution with binomial significance testing for non-response rate.
