# Project 2025 → Repository Hit-Rate Analysis

**Purpose**: Cross-reference the 30 chapter directives of Project 2025's *Mandate for Leadership* against what has actually happened in the real world (2025–2026), to see how much of the blueprint was executed, how much was attempted and then blocked or reversed, and how much simply didn't happen.

**Method (three passes)**:
- **Pass 1 (repo-only)**: cross-referenced each chapter against events already documented inside this repository's own `_AI_CONTEXT_INDEX/` corpus. Chapters with nothing in the repo got a single placeholder row tagged `NO REPO MATCH`.
- **Pass 2 (web-researched)**: the repo owner's own research surfaced a blindspot Pass 1 couldn't see — several directives were *implemented and then blocked, vacated, or reversed by courts, Congress, or other checks*. Pass 2 extended the same rigor (real, dated, cited sources; explicit search for blocked/reversed outcomes) to every chapter, adding specific, dated sub-directive rows.
- **Pass 3 (cleanup, after five correction rounds — four external reviews plus the repo owner's own fact-check)**: Pass 3 is the umbrella name for all correction work on top of Pass 1/2; the Correction Log below breaks it into Round 1 through 5, one per review/fact-check pass that triggered it (Gemini; a dedicated Claude review session; that same session's follow-up on its own prior fix; a GitHub Copilot automated PR review; the repo owner's own fact-check against a new event-level CSV). Across the five rounds, Pass 3 fixed: (1) added a fifth outcome category, `AFFIRMATIVELY CONTRADICTED`, for rows that were mistagged `NO MATCH FOUND` when the real finding was "the opposite happened" — and then had to tighten that category's own application after a false positive slipped in (see Round 4); (2) **removed 21 stale Pass‑1 `NO REPO MATCH` placeholder rows that were left in place after Pass 2 added real research for the same chapter** — these were pure duplication, the actual cause of the CSV feeling "scattered," and every single one has since-researched rows elsewhere in the file; (3) added `Chapter_Num`, `Pass`, and `Why_No_Match` columns, and sorted the whole file by chapter number so appended research no longer determines row order; (4) fixed two rows where a status upgrade had been applied without updating the `Date`/`Repo_Event` text to match, leaving the row contradicting itself, and corrected two factual errors (a wrong court docket number, mortgagee-letter numbers attributed to the wrong date) that surfaced during that fix; (5) corrected eleven date/figure errors caught by the repo owner's own independent fact-check, none of which changed a row's outcome status. See the Correction Log at the bottom for exactly what changed and why.

**Companion file**: `project_2025_mapping.csv` — 125 data rows across all 30 chapters, columns: `Chapter_Num, Date, Chapter, Directive, Repo_Event, Verification_Status, Why_No_Match, Pass, Repo_Source_File`. `Pass` is `1` for rows sourced from this repo's own corpus and `2` for rows from live web research (the `Repo_Source_File` column also marks Pass‑2 rows with `[web research — not repo corpus]`). `Why_No_Match` is filled in only for the 5 rows that are still genuinely `NO MATCH FOUND` after Pass 3's cleanup, explaining *why* (needs Congress, achieved informally via a different mechanism, not addressed either way, or unknowable from public sources).

**Second companion file**: `project_2025_events.csv` — 214 rows, one per individual dated event rather than one per directive, linked back to `project_2025_mapping.csv` by `CSV_Row`/`Chapter_Num`. Built by the repo owner as an independent fact-check layer (see Round 5 in the Correction Log below); its `Date_Check` column records what was reconfirmed, flagged, or left as originally researched.

**Outcome categories used throughout** (this repo's own ✅/⚠️/🔍 convention, extended with three categories this analysis needed):
- `VERIFIED` — action confirmed by credible sources, not currently blocked or reversed
- `ATTEMPTED — BLOCKED/REVERSED` — the action was taken, then blocked, enjoined, vacated, or reversed by a court, Congress, or (in one case) the agency itself under public pressure — name the mechanism
- `PARTIALLY VERIFIED` — confirmed but outcome is unresolved, forward-looking, proposed-not-final, or only partially executed
- `AFFIRMATIVELY CONTRADICTED` — added after an external review of the CSV caught a real gap: several directives weren't just unmet, they were *inverted* — the administration, Congress, or a court took action in the opposite direction from what the chapter asked for (e.g., a subsidy program was expanded when the chapter called for its elimination). This is distinct from `NO MATCH FOUND`, which means nothing relevant happened at all — "no evidence" and "the opposite happened" are different findings and now get different tags.
- `NO MATCH FOUND (web-researched)` — genuinely nothing found after real search (successor to Pass 1's "NO REPO MATCH," now meaning "we checked the open web, not just the repo, and still found nothing")

Three numbers to read carefully: **26 of 125 tracked sub-directives (21%) were actively attempted and then hit a wall** — a court injunction, a Supreme Court ruling, a congressional rejection, or, in one case, the agency itself backing down under public pressure; **8 more (6%) went further still: the real-world outcome was the *opposite* of what the chapter asked for**, not merely a failed attempt — meaning some actor (an administration, Congress, or a court) took a specific, documented action running counter to the chapter's text, not just inaction plus an unrelated trend; and after Pass 3's cleanup, only **5 of 125 (4%)** are genuinely "we looked and found nothing." That's a much smaller and more honest number than the 28–35 that earlier, uncleaned versions of this file implied, because those counts were inflated by stale duplicate rows rather than real gaps. Below, a chapter-by-chapter verdict, then the cross-cutting patterns worth knowing.

## Cross-Cutting Patterns

1. **The blindspot the owner caught is real and large.** 26 of 125 rows are attempted-then-blocked/reversed — concentrated in Ch.8 (media agencies), Ch.11 (Education), Ch.24 (Fed), Ch.26 (Trade/Section 122), and Ch.27 (CFPB), which together account for well over half of all blocked/reversed rows. These chapters are the best evidence that "Project 2025 was implemented" is too simple a claim — the more accurate picture, at least for these five, is "attempted aggressively, contested aggressively, outcome still unsettled."

2. **A new outcome the original three-category framework didn't anticipate: blocked-then-achieved-anyway, via a different route.** Ch.8's CPB defunding is the clearest example — a court blocked the executive order on First Amendment grounds, and the administration got the same result anyway through a $9 billion congressional rescissions package. **This is deliberately logged as two separate rows** (one `ATTEMPTED — BLOCKED/REVERSED` for the EO, one `VERIFIED` for the rescission that achieved the same goal), not a double-count of a single event — the CSV counts sub-directive *attempts*, and CPB's underlying directive really was attempted twice, via two different mechanisms, with two different outcomes. Reading only the row-level tallies without this context could make Ch.8 look more "blocked" than it ultimately was — the chapter's goal (CPB defunded) was, in the end, achieved.

3. **Another new outcome: self-halted, not court-blocked.** Ch.20's VA disability-rating rule was suspended by the Secretary within 48 hours of public backlash — no court, no congressional vote, just political retreat. This is a third failure mode alongside judicial and legislative blocks, worth watching for elsewhere.

4. **A fourth outcome, and a real gap in the original methodology that an external review caught: `AFFIRMATIVELY CONTRADICTED`.** Eight rows show some actor — an administration, Congress, or a court — taking a specific, documented action in the *opposite* direction from the chapter's text, not just failing to act: Ch.10 (sugar subsidies increased to a 40-year high by Congress, not eliminated; GMO labeling expanded by a court order, not repealed), Ch.19 (FAA privatization explicitly declined by DOT's own Secretary), Ch.22 (existing tax brackets and 21% corporate rate kept by statute, not the chapter's two-rate/18% plan — twice), Ch.23 (Ex-Im Bank expanded, not abolished — the *opposing* essay's author's position won), Ch.25 (SBA guidance pushes survivors toward SBA loans, not private insurance), and Ch.30 (antitrust enforcement not reduced). These rows were originally mistagged `NO MATCH FOUND`, which implied nothing had happened — inaccurate, since in every one of these cases a specific, documented action *did* happen, just the reverse of what Project 2025 asked for. The category is deliberately narrow: it requires an actual enacted action, not just an outcome trending the wrong way on its own — Ch.10's school-meals CEP directive was briefly tagged this way too (participation grew, but via no policy action at all) and was reverted to `NO MATCH FOUND` once that distinction was pointed out, specifically to keep this category meaning what it says. See the Correction Log for the full back-and-forth.

5. **Personnel-loyalty and purge patterns still repeat across Ch.1, 3, 4, 5, 6, 7, 17.** This was true in Pass 1 and remains the dataset's most consistent throughline: whatever else diverged from the text, the drive to replace career/independent staff with loyalists shows up almost everywhere Pass 2 looked.

6. **The Judiciary — not Congress — is doing most of the blocking.** Of the 26 blocked/reversed rows, the clear majority involve a federal court (district court, circuit court, the Court of International Trade, or the Supreme Court) as the blocking mechanism; Congress rejecting a proposal (Ch.11's Title I/IDEA block grants, Ch.21's EDA elimination) is the second most common path; only Ch.20's VA case involved neither.

7. **A fifth, purely mechanical finding worth naming: most of the "no match" problem wasn't research — it was file hygiene.** A second independent review (a dedicated Claude session set up to audit this exact file) found that this CSV's layered construction — Pass 1 wrote one placeholder row per unmatched chapter, then Pass 2 *appended* real research for those same chapters without deleting the placeholders — left 21 stale, superseded `NO REPO MATCH` rows sitting right next to the chapters' real findings. That's most of why the file felt "scattered" and hard to navigate: roughly a sixth of all rows were dead weight. Removing them didn't change a single finding; it just stopped the file from contradicting itself (a chapter that says both "no match" and "here are six researched sub-directives" in different rows is confusing even when both statements were separately true at different points in the process).

## What This Does *Not* Show

This is still not an independent, comprehensive audit of full Project 2025 implementation — the Center for Progressive Reform/Governing for Impact tracker (53%, 283/532 actions) and project2025.observer (~48%) already do that at a scale and with a methodology this file doesn't replicate. What this file adds that a simple percentage doesn't: **which specific attempts were fought to a standstill, how, and by whom** — the texture behind the headline number, including several cases (Ch.22, Ch.23, Ch.30) where the real-world outcome ran opposite to the chapter's own text.

Every row's sources are named, real, dated outlets (courts, Federal Register entries, wire services, and beat reporters — never fabricated or invented) and are recorded in the `Verification_Status` and `Repo_Source_File` columns of the CSV. Rows carried over from Pass 1 (chapters 1–5, 9, 17) are sourced from this repository's own `_AI_CONTEXT_INDEX/` corpus; Ch.26 and Ch.28 have a mix of Pass 1 repo-sourced rows and later web-researched rows added once those two chapters were revisited; every other row is from live web research conducted specifically for this analysis and is marked `[web research — not repo corpus]` in the source column.
